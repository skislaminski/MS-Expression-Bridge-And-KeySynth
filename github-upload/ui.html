Learn a parameter for preset

  1. On the MS-60B+, select the effect the expression pedal should control.
  2. Turn the knob you want all the way down and all the way up, once.
  3. Click “Apply”.

Assignments per preset

No assignments yet. Enter a preset number and click “Add preset”.

The expression pedal can control up to four parameters per preset at once. “Heel” and “Toe” set the value a parameter has at each end of the pedal’s travel: use them to limit the range (e.g. 20 to 70) or to invert the direction (e.g. 100 to 0). Effect and parameter numbers follow the order on the pedal. If the pedal does not accept a parameter, sending to it stops and the preset shows a note above.
